# Challenge record — F-013: a skipped optional port slid the next argument into its slot

```text
Challenge:                  found while writing the F-012 test; pinned by metamorphic
                            causal-flag-vs-explicit-mask and shapes test (F-013)
Source/paper:               —  (§12 attention call forms)
TENSA features stressed:     catalog ops with layer-style optional ports
                            (`attention(query:, key:, value:, mask:)`), named arguments
TENSA implementation:
    dim B
    dim T
    dim D = 16
    model M(x: Tensor[B, T, D]) -> Tensor[B, T, D] {
      return attention(query: x, mask: causal_mask(T), heads: 4)
    }
Check result (before):      the optional tensor ports were collected in ORDER OF
                            APPEARANCE, so with `key:` and `value:` omitted the mask
                            became input 1 (the key) and, through the key←value default,
                            input 2 (the value). The checker then reported a bewildering
                            "attention key width" mismatch (T vs D) — or, worse, for a
                            mask whose trailing extent happened to equal D, nothing.
Check result (after):       ok; the mask reaches input 3. A skipped optional port keeps
                            its slot and defaults to the port before it: key ← query,
                            value ← key. `attention(query: q, key: kv, mask: m)` is
                            therefore value = kv, mask = m, exactly as the port list reads.
Runtime result (after):     causal-flag-vs-explicit-mask: `attention(heads: 2, causal: true)`
                            and `attention(query: x, mask: causal_mask(T), heads: 2)`
                            produce equal outputs to 1e-5.
Reference result:           PyTorch `F.scaled_dot_product_attention(q, k, v, attn_mask=…)`
                            — keyword arguments cannot slide.
Finding classification:     F (argument binding was positional under the hood; named
                            ports lied)
Severity:                   major — a named port silently bound to the wrong slot
Proposed action:            DONE — `analyze.ts` catalog call: iterate `spec.optionalPorts`
                            up to the LAST named one; a named port pushes its value, an
                            unnamed one before it re-pushes the previous tensor input.
Language change required?:  no
Regression test added?:     yes — shapes / "optional ports keep their position:
                            attention(mask:) does not slide into the key slot (F-013)";
                            metamorphic causal-flag-vs-explicit-mask; F-012's rank-4 case
                            (`attention(query: q, mask: pad)`) depends on it
```
