# Challenge record — H-008: runtime and emitter disagreed on what `every N steps` counts

```text
Challenge:                  curriculum-events (phase event + plan event), baseline-ceremony
Source/paper:               §22 events
TENSA features stressed:     `every N steps { … }` inside a phase and at plan level
TENSA implementation:
    phase hard { steps 6 ... every 3 steps { validate } }
    every 5 steps { checkpoint }
Runtime result (before):    `exec.ts` fired BOTH kinds of event on the step index within
                            the current phase; the emitter fired both on the global
                            step. For a plan-level `every 5 steps { checkpoint }` after a
                            4-step first phase the two backends checkpointed at
                            different moments — the reference and the reference of the
                            reference disagreed.
Decision:                   a phase-level event counts steps WITHIN its phase
                            (`phase_step`); a plan-level event counts steps ACROSS the
                            run (`step`). Both fire when `(count + 1) % N == 0`; the
                            recorded `step` is the 0-based global step. Epoch events are
                            unchanged (`(epoch + 1) % N`).
Runtime result (after):     tests.ts: p1 = 3 steps with `every 2 steps { validate }`,
                            plan `every 4 steps { checkpoint }`, p2 stops by `until`
                            after 1 step → events `validate@1 checkpoint@3`.
Reference result:           emitted plan contains `if phase_step % 3 == 0:` for the phase
                            event and `if step % 5 == 0:` for the plan event
                            (curriculum-events `emitContains`).
Finding classification:     H (two backends, one IR, two readings)
Severity:                   minor — checkpoints/validation at shifted steps
Proposed action:            DONE — `exec.ts` `fireEvents(phase.events, name, s);
                            fireEvents(plan.events, name, step)`; `emit_torch.ts`
                            `emitEvents(..., "phase_step")` / `(..., "step")`.
Language change required?:  no (documented in docs.ts HARDENING)
Regression test added?:     yes — `lifecycle / plan-level events count run steps, phase
                            events count phase steps; `until` ends a phase (H-001,
                            H-008)`; challenges `curriculum-events`, `baseline-ceremony`
                            (`emitContains`)
```
