# Challenge record — E-008: a refuted data↔model axis is a contract failure, not a shape clash

```text
Challenge:                  vision-pipeline (twins `wrong-layout`, `wrong-channels`,
                            `target-kind`); semantic `objective-graph`
Source/paper:               §19–§20 data plane contracts
TENSA features stressed:     `field image: Image[8, 8, 3]` bound to a model input
                            `Image[B, 3, 8, 8]`; greyscale `Image[1, 8, 8]` bound to a
                            3-channel input; `Tokens[1]` label on a `Class[B]` port
Check result:               all three refute. The question was WHICH code. The generic
                            shape engine says AXS0401 ("shape mismatch"); the data
                            plane says AXS0602 ("field … per example but model input …
                            expects …") / AXS0603 for objective ports. Before this
                            decision the wrong-layout twin got AXS0401 from `eqDim`
                            while wrong-channels got AXS0602 from the rank/width check
                            — the same mistake, two codes, depending on which axis
                            happened to differ.
Decision (2026-09-17):      a refuted axis between a data field and a model input, or
                            between a model output and an objective port, is reported
                            under the CONTRACT code (AXS0602 / AXS0603) with the axis
                            named ("field 'image' -> model input 'image' axis 1").
                            AXS0401 remains the code for shape clashes INSIDE a graph.
                            `eqDim` takes the code as a parameter for this.
Runtime result:             n/a (compile-time refutation)
Finding classification:     E (design decision about diagnostic taxonomy)
Severity:                   minor
Proposed action:            DONE — `analyze.ts` model/data compatibility loop passes
                            "AXS0602" to `eqDim`; loss bindings pass "AXS0603".
Language change required?:  no
Regression test added?:     yes — challenge `vision-pipeline` twins (expectCodes AXS0602)
```
