# Challenge record — F-017: an optimizer (or loss) no phase applied was accepted silently

```text
Challenge:                  gan-alternating (twin `generator-never-updated`)
Source/paper:               GAN alternating updates (Goodfellow et al. 2014), §26 item 6
TENSA features stressed:     two optimizers over two models, per-phase `update … with …`
                            and `times`
TENSA implementation:
    train Gan {
      model G = Gen      model D = Disc
      loss d_loss = DiscLoss(real: D(x), fake: D(G(z)))
      loss g_loss = GenLoss(fake: D(G(z)))
      optimizer g_opt = adamw(lr: 2e-4) over G
      optimizer d_opt = adamw(lr: 2e-4) over D
      phase main { steps 8  update d_loss with d_opt times 2 }   # g_loss / g_opt forgotten
    }
Check result (before):      ok — `g_opt` claimed the generator's tables (so the
                            overlapping-optimizer check was happy) and no phase ever
                            stepped it; `g_loss` was compiled, never back-propagated.
                            The discriminator trained against a frozen generator with
                            no diagnostic.
Check result (after):       AXS0708 warnings at the plan: "optimizer 'g_opt' is not
                            applied by any phase; the N parameter table(s) it covers are
                            never trained" and "loss 'g_loss' is declared but no phase
                            updates it".
Runtime result:             (un-mutated) both optimizers applied, 2:1 ratio visible as
                            plan data (`times`), every table of G and D updated.
Reference result:           PyTorch: an optimizer you never `.step()` is just an object.
Finding classification:     F (the plan's "every declared optimizer/loss participates"
                            contract was unchecked)
Severity:                   major — silent half-training
Workaround:                 read the emitted plan
Proposed action:            DONE — `analyze.ts` after phase derivation: an optimizer with
                            parameters that no update names, and a loss no update
                            names, each warn AXS0708.
Language change required?:  no
Regression test added?:     yes — challenge `gan-alternating` twin
                            `generator-never-updated` (warnCodes AXS0708)
```
