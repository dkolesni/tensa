# Challenge record — F-012: attention / masked_fill mask shapes were unchecked

```text
Challenge:                  cross-attention-padding (tensor.ts), twins catalog-mask-rank /
                            catalog-mask-query-length / manual-mask-not-lifted /
                            manual-mask-cannot-broadcast
Source/paper:               —  (§12 masks: causal + padding; cross attention)
TENSA features stressed:     `attention(mask:)`, `masked_fill`, Mask kind, broadcasting
                            against [B, Heads, Tq, Tk]
Expected semantics:         a padding mask indexes the KEY sequence and broadcasts over
                            heads and queries; a causal mask is [Tq, Tk]. A mask of the
                            wrong length (T for S) or the wrong rank must be a static
                            error, and a mask that is legal must reach the right axes at
                            runtime.
TENSA implementation:
    dim B
    dim T
    dim S
    dim D = 16
    dim Heads = 2
    model X(q: Tensor[B, T, D], kv: Tensor[B, S, D], pad: Mask[B, 1, S]) -> Tensor[B, T, D] {
      return attention(query: q, key: kv, value: kv, mask: pad, heads: Heads)
    }
Check result (before):      ok for ANY mask: `attention` only required the port to be a
                            Mask; `masked_fill` only checked the kind. `pad: Mask[B, 1, T]`
                            (query length instead of key length) and `Mask[B, 1, 1, S]`
                            compiled clean.
Runtime result (before):    a rank-3 mask [B, 1, S] trailing-broadcast against scores
                            [B, Heads, T, S] → its B axis landed on the HEADS axis; with
                            B = Heads it ran silently wrong, otherwise it crashed inside
                            the tensor library.
Check result (after):       contract `Mask[Tq, Tk]` (rank 2) or `Mask[B|1, Tq|1, Tk]`
                            (rank 3; constant 1 broadcasts). Rank 4 → AXS0402 "attention
                            mask must be Mask[Tq, Tk] or Mask[B, Tq, Tk] (1 broadcasts),
                            received rank 4". `Mask[B, 1, T]` with T=5, S=3 → AXS0401
                            (5 ≠ 3, refuted); symbolic → carried. `masked_fill` now checks
                            trailing broadcast: mask rank > operand rank → AXS0402,
                            otherwise each trailing-aligned axis must equal or be 1.
Runtime result (after):     rank-3 masks are lifted to [B, 1, Tq, Tk] before the fill;
                            cross-attention-manual-vs-catalog pair equal to 1e-4 at
                            B=2, T=5, S=3.
Reference result:           PyTorch SDPA `attn_mask` must broadcast to [B, H, L, S]; the
                            padding-mask idiom is `mask[:, None, None, :]`. Note the
                            polarity: TENSA Mask true = BLOCKED, SDPA bool mask true =
                            ALLOWED — the emitter negates (`~m`, H-005).
Finding classification:     F (missing constraint = false certainty, plus a runtime
                            misalignment behind it)
Severity:                   major — the exact port §12 asks to torture
Proposed action:            DONE — `catalog.ts` attention `infer` mask rule (warn AXS0409
                            if not a Mask kind; rank-2/rank-3 `c.eq` per axis with the 1
                            exemption; anything else AXS0402); `masked_fill` trailing
                            broadcast rule; `exec.ts` lifts rank-3 masks. Padding masks
                            are written `Mask[B, 1, S]` by contract.
Language change required?:  no (library contract of a catalog op)
Regression test added?:     yes — shapes / "attention and masked_fill check the mask
                            shape (F-012)"; challenge:cross-attention-padding (+ 4 twins);
                            metamorphic cross-attention-manual-vs-catalog
```
