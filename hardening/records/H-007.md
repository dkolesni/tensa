# Challenge record — H-007: nested model bindings `D(G(z))` gave the inner model no gradient

```text
Challenge:                  gan-alternating (run, gradAll); distillation, self-training
                            (`Teacher(x)` inside a loss binding), contrastive-views
Source/paper:               GAN (§26 items 1–3), knowledge distillation (§26 item 7)
TENSA features stressed:     objective-port bindings that compose models
                            (`D(G(z))`, `Enc(augment(x))`, `Student(x)`), the
                            reference runtime's synthetic data
TENSA implementation:
    loss d_loss = DiscLoss(real: D(x), fake: D(G(z)))
    loss g_loss = GenLoss(fake: D(G(z)))
Runtime result (before):    the interpreter parsed a binding as `<model>(<field>)` only.
                            `D(G(z))` looked up a field literally named `G(z)`, got a
                            fresh synthetic tensor, and fed it to D: the generator was
                            never on the tape, so `g_loss` produced no gradient for G
                            and the coverage report said "no gradient path reached
                            this parameter" for every generator table — a false
                            positive of the kind H-002 had already taught us to fear.
                            The emitter had the mirror image: `batch["G(z"]`.
Runtime result (after):     `evalBinding` recurses: a model call's arguments are
                            themselves bindings (model calls, tuple indices `Enc(x)[1]`,
                            or field names). Every model on the path is on the tape. A
                            per-step field cache returns the SAME synthetic tensor for
                            the same field name, so `augment(x)` and `x` in one binding
                            agree. gan-alternating: gradAll after 6 steps.
Reference result:           emitted plan lowers the binding recursively:
                            `objective_DiscLoss(D(batch["real"]), D(G(batch["z"])),
                            dims=dims)`; forbidden pattern `batch["G(z"` is asserted.
Finding classification:     H (runtime and emitter binding lowering)
Severity:                   major — the flagship two-player program reported wrong
                            gradient coverage
Proposed action:            DONE — `exec.ts` `evalBinding` / `fieldCache`; `emit_torch.ts`
                            binding lowering.
Language change required?:  no
Regression test added?:     yes — challenge `gan-alternating` (`run.gradAll`,
                            `emitContains` nested call, `emitForbids`); `distillation`,
                            `self-training` run checks
```
